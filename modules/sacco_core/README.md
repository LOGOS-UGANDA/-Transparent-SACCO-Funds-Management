# sacco_core

Headless Logos **core module** for Transparent SACCO.

## Role

- Call the `fee_transparency` LEZ program / wallet APIs
- Expose IPC methods used by `sacco_ui` (and optionally other clients)
- Optionally integrate Logos Storage for release evidence (CID references)

## Status

Scaffold only. Implement with [`logos-module-builder`](https://docs.logos.co/core/build-modules/build-and-run-a-logos-core-module) once the LEZ program interface is stable.
